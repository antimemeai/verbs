# Verbs

stronger claims about their work. Keep the machinery small and owned.

Read README.md for the current behavior, journal/ for decisions, and
REGISTRIES.md before publishing. Registry availability is not ownership.

Use no runtime dependencies. Discuss any proposed library adoption first.
Keep PDFs, context/, quarantine/, credentials, and generated artifacts ignored.
Record meaningful work in journal/. Track remaining work in GitHub issues.
